# Unveil the Magic Behind Zero-Click Deployment
## Deploy Eleventy to IONOS using Continuous Deployment

Have you ever wondered about the 'magic' behind those deployment services like IONOS Deploy Now that ship your website instantly?

This repository replicate and enhance this magic using GitHub Actions and deployed a [website](https://cd-sample.kinneko.de/) created with eleventy.

Read my [article](https://medium.com/@kinneko-de/d5e22b061008), where I explain the concept in detail.

The repository has a long living feature branch 'feature/sample-feature/' where you can see how you can preview changes.
